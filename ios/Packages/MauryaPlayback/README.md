# MauryaPlayback 灯效播放

这是面向 volatile ESP32 灯效会话的结构化并发调度器。调用方拥有并等待 run；取消、暂停、断开、END 和输入清理都进入同一条有界清理路径，不创建 detached task，不使用忙等循环。

## 调度规则

- 组帧目标 10 Hz，逐灯 RGB 帧目标 20 Hz，心跳目标 1 Hz，且只允许一个传输请求在途。
- 使用单调绝对 deadline；中间帧过期时合并而不是无限排队；每个帧序号必须在 ACK 中回显。
- 当前 42 颗 RGB888 请求在协议上为 140 字节，7 组帧使用组优先布局。
- 必需输入沿用 Android 的一秒启动宽限；超过严格的 1000 ms 边界会返回 staleRequiredInputs 并执行 END/清理。
- 断线到新的 BEGIN ACK 期间冻结效果时间线，重新准备输入并重新开始一秒预热。

## 生命周期和验证

前台播放支持暂停/恢复；进入后台默认暂停，不承诺后台固定心跳或 20 Hz BLE。真实设备还需验证两小时前台播放、30 分钟逐灯帧、重连、内存、温度、电量和输入提供器清理，不能把包测试写成持续后台播放承诺。
