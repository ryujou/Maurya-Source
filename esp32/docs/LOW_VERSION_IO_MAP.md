# Lumia ESP32-C3 Low Version IO Map

更新时间：2026-06-14

## 概述

当前低配版固件已经固定为：

- ESP32-C3 常供电
- 7 路独立 WS2812 光棒
- 每组固定 6 颗灯
- BLE 保留
- BMI160 已删除
- GPIO9 为模式按键
- GPIO4 为运行/休眠拨档输入

这份文档按当前已经实现并测试通过的固件状态整理，可直接用于 PCB 布局与连线确认。

## 已占用 IO

### 7 路 WS2812

| 功能 | GPIO | 方向 | 说明 |
|---|---:|---|---|
| LED_CH1 | GPIO0 | 输出 | WS2812 第 1 路 |
| LED_CH2 | GPIO1 | 输出 | WS2812 第 2 路 |
| LED_CH3 | GPIO3 | 输出 | WS2812 第 3 路 |
| LED_CH4 | GPIO7 | 输出 | WS2812 第 4 路 |
| LED_CH5 | GPIO10 | 输出 | WS2812 第 5 路 |
| LED_CH6 | GPIO21 | 输出 | WS2812 第 6 路 |
| LED_CH7 | GPIO20 | 输出 | WS2812 第 7 路 |

说明：

- 当前逻辑模型为 `7 组 x 6 颗 = 42 颗`
- 每个 IO 控制一个完整光棒
- 不再使用前半区/后半区镜像方案

### 左到右布置时的推荐接法

如果实物是 `7` 根光棒从左到右排开，推荐直接按下面顺序接：

| 物理位置 | 光棒编号 | GPIO |
|---|---|---:|
| 最左侧 | Bar1 | GPIO0 |
| 左 2 | Bar2 | GPIO1 |
| 左 3 | Bar3 | GPIO3 |
| 中间 | Bar4 | GPIO7 |
| 右 3 | Bar5 | GPIO10 |
| 右 2 | Bar6 | GPIO21 |
| 最右侧 | Bar7 | GPIO20 |

软件里当前也是按这个顺序理解各组：

- 第 1 组 = 最左侧光棒
- 第 7 组 = 最右侧光棒

每根光棒内部的 6 颗灯，按该光棒灯带本身的 `DIN -> DOUT` 顺序编号。

建议：

- 所有光棒的 `DIN` 朝向尽量统一
- 例如全部从下往上，或者全部从左往右
- 不要出现有的光棒正向、有的光棒反向

如果某些光棒因为结构原因必须反着装，后续需要在软件里增加“单组反向映射”支持。

### 板载状态与按键

| 功能 | GPIO | 方向 | 说明 |
|---|---:|---|---|
| BLE 状态灯 | GPIO8 | 输出 | 板载 LED，低电平点亮 |
| 模式按键 | GPIO9 | 输入 | 板载 Boot 键复用，低电平有效，已做软件消抖 |

### 休眠控制

| 功能 | GPIO | 方向 | 说明 |
|---|---:|---|---|
| 运行/休眠拨档 | GPIO4 | 输入 | 高电平运行，低电平请求 deep sleep，软件消抖 30ms |

当前固件行为：

- `GPIO4 = High`：设备正常运行
- `GPIO4 = Low`：固件先发送 LED 全灭数据，再进入 `deep sleep`
- 进入 `deep sleep` 后，配置 `GPIO4` 为高电平唤醒
- `GPIO4` 回到高电平后，ESP32 被唤醒并重新启动

硬件要求：

- `GPIO4` 只能接 `3.3V` 或 `GND`
- 不允许接 `VBUS` 或任何 `5V`
- ESP32 本体必须常供电，这样 deep sleep 才有意义

推荐连接：

- 拨档公共端接 `GPIO4`
- 一档接 `3.3V`
- 一档接 `GND`

### 预留/空闲

| 功能 | GPIO | 方向 | 说明 |
|---|---:|---|---|
| 预留空闲 | GPIO6 | 未使用 | 当前已从固件中释放 |
| 预留空闲 | GPIO5 | 未使用 | 当前最干净的备用 IO |

## 电源与开关建议

推荐使用双刀拨动开关：

1. 一刀切灯电源
   - 左档：灯电源接通
   - 右档：灯电源断开

2. 一刀切 `GPIO4`
   - 左档：`GPIO4 -> 3.3V`
   - 右档：`GPIO4 -> GND`

对应行为：

- 左档：灯有电，设备运行
- 右档：灯断电，设备熄灯后进入 deep sleep
- 再拨回左档：设备被 `GPIO4` 高电平唤醒

## 不再使用的功能

| 功能 | 状态 | 说明 |
|---|---|---|
| BMI160 SDA | 删除 | 原 GPIO4 已释放给休眠拨档 |
| BMI160 SCL | 删除 | 原 GPIO5 已释放为备用 |
| 手动画点模式 | 删除 | 不再保留像素直写方案 |
| 高配版差异逻辑 | 删除 | 当前工程仅服务低配版 |

## PCB 布线注意事项

1. `GPIO4` 休眠控制必须是 `3.3V IO`
   - 不能接 `5V`
   - 不能接 `VBUS`

2. `GPIO9` 是 Boot 键复用
   - 不要外接可能影响下载启动的强驱动
   - 仅适合做本地功能按键

3. 7 路 WS2812 输出建议预留串联电阻位
   - 常见可放 `33R` 到 `100R`
   - 便于抑制边沿振铃和长线干扰

4. 灯电源与主控电源要区分
   - ESP32 常供电
   - 灯电源可由拨档单独切断

5. `GPIO5` 与 `GPIO6` 当前都可作为后续扩展备用 IO

## 当前固件默认配置

| 项目 | 当前值 |
|---|---|
| BLE 名称 | `Peacock` |
| LED 组数 | `7` |
| 每组灯数 | `6` |
| 默认效果 | 橙色常亮 |
| 模式按键消抖 | `30ms` |
| 休眠拨档消抖 | `30ms` |

## Effect Modes

| Mode | 含义 | Param 语义 |
|---|---|---|
| `1` | 整组流水 | 组间流水速度 |
| `2` | 爆闪 | 爆闪周期 |
| `3` | 常亮 | 亮度 |
| `4` | 呼吸 | 呼吸速度 |

说明：
- `Mode 1` 现在是 7 组之间轮流点亮，每次点亮一整根灯棒。
- 不再使用“组内尾迹流动”或“组内双向对冲”。
