# Lumia ESP32-C3 Low Version Context

当前仓库只维护低配版固件，工程根目录为 `lumia_esp32/`。

当前架构约束：

- 主控：ESP32-C3
- 通信：BLE + USB Serial Modbus RTU
- 灯效输出：7 路独立 WS2812
- 每组固定 6 颗灯，共 42 颗
- 不使用 BMI160 或任何 IMU
- 效果模型为双层：
  - `组内层`：单根灯棒的整组颜色/亮度变化
  - `组间层`：7 组之间的扫描和运动
- 不兼容旧寄存器语义
- 不迁移旧 Flash 配置

工程原则：

1. 以当前低配版硬件和协议为唯一目标，不再维持旧版本兼容层。
2. 所有效果配置都通过新寄存器模型管理，并持久化到内部 Flash。
3. 组内层只做整组颜色/亮度变化，不做组内位置运动。
4. 组间层统一为全局 scene，不支持每组独立 scene。
5. GPIO9 只切换 scene，GPIO4 负责深度睡眠唤醒控制。
