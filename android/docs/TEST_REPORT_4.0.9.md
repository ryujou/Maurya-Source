# Maurya 4.0.9 本地发布测试报告

## 修复内容

- 代码编辑器和积木编辑器共用同一套动态底部安全区算法。
- 不再只信任部分厂商系统可能返回错误的 `getWindowVisibleDisplayFrame()`：
  - 同时读取物理显示高度、窗口可见区域和导航栏/软键盘 Insets。
  - 以“预览/播放”按钮在屏幕上的实际坐标做二次校验。
  - 若按钮底边仍越过真实可见区域，立即增加自校正间距，直至按钮完整可见。
- 屏幕旋转、分辨率、显示密度、字体倍率、导航方式和软键盘变化后自动重新测量。
- 保留代码滚动编辑、空白工作区平移、积木拖动和字段编辑行为。
