# Maurya 4.0.8 本地发布测试报告

## 修复内容

- 移除效果编辑器底栏固定 `24 dp` 补偿。
- 从 Android Dialog 根视图实时读取：
  - 根视图在屏幕上的实际底边。
  - `getWindowVisibleDisplayFrame()` 返回的当前可见底边。
  - 导航栏实际像素 Insets。
  - 软键盘实际像素 Insets。
- 屏幕旋转、分辨率、显示密度、导航方式、键盘和窗口布局变化时自动重新计算底部避让距离。
- 保留空白工作区拖动平移、积木拖动和字段编辑行为。
